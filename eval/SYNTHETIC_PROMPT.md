# Генерация синтетических вопросов (этап подготовки)

ТЗ разрешает проприетарные модели **только на этапе подготовки** и просит честно сказать об этом на питче.
В рантайме системы они не используются. Ключи API в репозиторий не кладём.

## Как пользоваться

1. Выберите 10–20 чанков каждой компании из `index_data/chunks.jsonl` (разные документы и типы: текст, строки таблиц, записи).
2. Вставьте их в промпт ниже вместо `{CHUNKS}`.
3. Ответ сохраните в `eval/questions.synthetic.json` и проверьте глазами: вопросы должны быть похожи на то, что спросит сотрудник.
4. Прогон: `python -m eval.evaluate eval/questions.synthetic.json --full`.

Эти же вопросы с полем `company` годятся для дообучения роутера (`NCM.add_examples`).

## Промпт

```
Ты готовишь тестовый набор для RAG-системы по документам компании.
Ниже фрагменты документов, у каждого указан файл, страница/строка и компания.

{CHUNKS}

Составь 15 вопросов на русском, как их задал бы сотрудник:
- 10 вопросов, ответ на которые есть ровно в одном фрагменте; спрашивай конкретные факты
  (числа, сроки, названия, условия), формулируй своими словами, а не копируй текст;
- 2 вопроса «где в документе описано …» (ответ — файл и страница/пункт);
- 3 вопроса по теме компании, ответа на которые во фрагментах НЕТ.

Верни JSON-массив объектов:
{"question": "...", "company": "<папка компании>", "expected_doc": "<файл>",
 "expected_page": <число или null>, "expected_contains": ["<ключевой факт из ответа>"],
 "answerable": true|false}
Для вопросов без ответа: expected_doc = null, expected_contains = [], answerable = false.
```
