# CLAUDE.md — контекст проекта для Claude Code

## Что это
Команда (4–5 человек) готовит RAG-систему к корпоративному хакатону. Чат-бот отвечает на вопросы
сотрудников по документам трёх компаний: `docs/tehnoprom/`, `docs/logistics/`, `docs/retail/`.
Требования и статус по каждому пункту ТЗ — в `TZ.md`. Правила работы в Git — в `CONTRIBUTING.md`.

## Жёсткие требования ТЗ (не нарушать)
- `POST /ask` по умолчанию отвечает строго `{"answer", "sources": [{"doc", "page", "score"}], "confidence"}`;
  всё остальное — только в `?debug=true`. `page` — число (страница PDF / абзац DOCX / строка таблицы / запись JSON).
- Нет ответа в документах → ровно «Нет в документах» (`config.NO_ANSWER`), источники пустые.
- В рантайме только локальные open-source модели (LLM до 13B через Ollama). Никаких платных API, ключей в коде, хардкода ответов.
- Скорость: цель < 2 с, максимум 5 с на CPU (4 ядра, 16 ГБ) ноутбука жюри.
- Воспроизводимость: `docker compose up --build` поднимает всё за 10 минут.

## Архитектура
вопрос → кэш → эмбеддинг (bge-m3) → роутер (`src/router/`: ключевые слова с начала слова + NCM по
центроидам документов) → гибридный поиск (`src/retrieve/`: numpy-векторы + BM25, RRF) → reranker
(bge-reranker-base) → порог `MIN_CONFIDENCE` (отказ без LLM) → при низкой уверенности повторный поиск
по всем компаниям → LLM (`src/generate/`, Qwen2.5 через Ollama, ссылки [n]) → источники по цитатам,
самопроверка чисел ответа.

## Зоны и владельцы
| Папка | Роль |
|---|---|
| `src/ingest/` | 1 — данные (парсеры, чанки, метаданные) |
| `src/retrieve/` | 2 — поиск |
| `src/generate/` | 3 — генерация |
| `src/router/`, `eval/` | 4 — роутер и оценка |
| `src/pipeline.py`, `src/api.py`, `src/web.html`, Docker, README | 5 — сборка |
| `src/schema.py` | общий контракт: менять только по договорённости всей команды |

Меняй код в зоне задачи; если правка задевает чужую папку или `schema.py`, скажи об этом явно.

## Команды
```bash
pytest -q                                          # тесты на фейковых моделях, без скачивания
python -m src.ingest docs                          # индексация (продолжает с места остановки; --force заново)
uvicorn src.api:app --port 8000                    # API + веб-интерфейс
python -m eval.evaluate eval/questions.json --full # метрики: hit@k, MRR, роутер, отказы, время
docker compose up --build
```

## Правила
- Новый модуль или поведение — с тестом в `tests/` (фейковый эмбеддер в `tests/conftest.py`).
- Настройки — через `.env` / переменные окружения (`src/config.py`), не правкой дефолтов под себя.
- Зависимости — с точной версией (`==`) в `requirements.txt`, отдельным PR.
- Не коммитить `docs/`, `index_data/`, модели, `.env`.
- Работа через ветки `feat/...`, `fix/...` и pull request в `main`; `main` всегда зелёный.
- Ответы пользователю и комментарии в коде — по-русски.

## Открытые вопросы
- Не проверено на реальных моделях: тесты PDF (PyMuPDF) и API (FastAPI), Docker, скорость на CPU.
- Уточнить у организаторов: названия компаний в вопросах, что меряют в скорости, точная фраза отказа.
- На хакатоне: подобрать `MIN_CONFIDENCE`, пополнить ключевые слова роутера по данным, ветка расчёта по тарифам.
